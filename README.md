# 피부과 랜딩 페이지

피부과의 진료 방향, 진료 분야, 내원 안내를 소개하는 한국어 단일 페이지입니다. HTML과 CSS만 사용하며 별도 패키지 설치나 빌드 과정이 필요하지 않습니다.

## 미리보기

브라우저에서 `index.html`을 열거나, Python이 설치된 환경에서 프로젝트 폴더에서 아래 명령을 실행한 뒤 `http://127.0.0.1:8000`에 접속하세요.

```powershell
py -m http.server 8000 --directory dist
```

## 파일 안내

- `index.html`: 랜딩 페이지 원본
- `dist/index.html`: 사이트 배포에 사용하는 정적 페이지
- `.openai/hosting.json`: 사이트 프로젝트 ID와 정적 파일 경로 설정

병원명, 주소, 진료 시간, 전화 상담, 예약 방법은 실제 정보가 확인되면 페이지의 `확인 필요` 문구를 수정하세요.
